## Goal
Talk about real and imaginary conditions with the right tenses.

## Explanation
- Type 1 - real/likely: **si + present → present / future / imperative**: S'il pleut, je reste à la maison. Si tu viens, on ira au cinéma. Si tu as faim, mange !
- Type 2 - imaginary/unlikely now: **si + imparfait → conditional**: Si j'avais de l'argent, j'achèterais une maison. Si j'étais toi, je partirais.
- **Never future or conditional right after si** (si = if): «Si j'aurais…», «Si je serai…» are wrong.
- si + il → s'il; si + elle stays si elle.
- The si-clause can come second: Je partirais si j'avais le temps.
- Type 3 (past regrets) → G34.

## Forms
| type | si-clause | main clause |
|---|---|---|
| 1 real | present | present / future / imperative |
| 2 imaginary | imparfait | conditional present |

## Examples
- Si tu veux, je t'aide. - If you want, I'll help you.
- S'il fait beau demain, nous irons à la plage. - If it's nice tomorrow, we'll go to the beach.
- Si j'avais plus de temps, j'apprendrais l'italien. - If I had more time, I'd learn Italian.
- Si j'étais riche, je voyagerais partout. - If I were rich, I'd travel everywhere.
- Que ferais-tu si tu gagnais au loto ? - What would you do if you won the lottery?

## Traps
- Conditional after si: «Si j'aurais de l'argent» → Si j'avais de l'argent.
- Future after si: «Si tu viendras» → Si tu viens.
- Mixing types: «Si j'ai le temps, je viendrais» → je viendrai.

## Mistake patterns
si j'aurais, si je serai, si tu viendras, mixing type 1 + conditional, si il.

## Quick check
1. Si nous ___ (partir) maintenant, nous arriverions à l'heure. → partions
2. «Если будет хорошая погода, мы пойдём гулять.» → S'il fait beau, nous irons nous promener.
3. fix: Si il pleut… → S'il pleut…
